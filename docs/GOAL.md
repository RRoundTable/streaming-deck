# Goal

## Primary Goal

키보드 단축키 하나로 업무 모드(시작 → 딥워크 ⇄ 휴식 → 마감)를 전환하고 그 기록이 Obsidian 기록 볼트에 자동으로 쌓이게 해서, 하루 딥 블록 3~4개를 안정적으로 확보한다.

> Stream Deck은 나중에 붙이는 스위치일 뿐이다. 모든 동작은 `bin/sd`에 두고, 지금은 Hammerspoon 키보드 단축키로 호출한다.

## Success Criteria

4주차(2026-10-25) 기준, 기록 볼트의 집중 로그로 측정한다.

- [ ] 하루 딥 블록 평균 3개 이상
- [ ] 블록 평균 집중도 3.5 이상
- [ ] MIT 완료 주 4일 이상, Shutdown 실행 주 5일
- [ ] 직접 손으로 쓰는 시간 하루 5분 이내 (넘으면 쓰는 항목을 줄인다)

## Out of Scope

- 팀 협업 도구 자체의 설계, 업무 볼트(연구·설계 노트) 구조
- 스마트폰 연동 (물리적으로 분리한다)
- 회고·주간 리뷰 답변, 집중도 점수의 자동 생성 — 숫자 집계만 자동, 의미는 사람이 쓴다
- Claude API 직접 호출 (LLM 판정은 `claude -p --model haiku` 헤드리스만)
- Stream Deck 트리거 플러그인 개발 — 버튼은 Hotkey 액션으로 같은 단축키만 연결 (표시 전용 플러그인은 adr/005. 예외: 캘린더 키는 누르면 Google Calendar를 연다, adr/006)
